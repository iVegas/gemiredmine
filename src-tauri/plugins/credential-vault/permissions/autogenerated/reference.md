## Default Permission

Lets the app keep and read the API keys of its servers in the Android Keystore, and set the fingerprint or face unlock.

#### This default permission set includes the following:

- `allow-save`
- `allow-load`
- `allow-remove`
- `allow-status`
- `allow-biometric`
